# ReplayCase v0.4.0

ReplayCase is the new name for NarrowsLink. This release renames the application,
repository, CLI, release assets, and current operator documentation. It preserves
the local-first telemetry capture, deterministic replay, incident investigation,
and verifiable evidence-handoff workflow.

## Install

Requires Node.js 20.19 or newer and a local browser. Download
`replaycase-0.4.0.tgz`, `replaycase-0.4.0.release.json`,
`replaycase-0.4.0.cdx.json`, and `SHA256SUMS` from this release.

On macOS:

```bash
shasum -a 256 -c SHA256SUMS
npm install --global ./replaycase-0.4.0.tgz --ignore-scripts
replaycase version --json
replaycase serve
```

On GNU/Linux, use `sha256sum -c SHA256SUMS`. Compare the reported version and full
commit with the release manifest. The command opens `http://127.0.0.1:47890/` and
manages the authenticated bridge without manual token transfer. Stop it with
`Ctrl+C`.

## Upgrade from NarrowsLink

Stop the old application and run `npm uninstall --global narrowslink` before
installing this package. Both packages provide the old command, so do not install
them side by side or force an executable overwrite. Use the same browser profile
and loopback origin to retain sessions, profiles, markers, notes, ranges, and
receiver findings. Uninstalling the npm package does not erase those stores or
exported files.

`narrowslink` remains an alias for the ReplayCase CLI. Both commands report
`name: "replaycase"` in version JSON. The new runtime discovery path is
`/replaycase-runtime.json`; the old path remains an alias. Current configuration
uses `REPLAYCASE_*` with legacy `NARROWSLINK_*` fallbacks.

## Evidence compatibility

Session versions 1 and 2 and bundle versions 3 and 4 remain readable. New bundles
remain version 4. File extensions, evidence-format identifiers, storage keys,
built-in decoder contents and hashes, parser runtimes, and raw records are not
renamed or rewritten. Existing v0.3.0 receivers can inspect v4 bundles from this
release; v0.2.0 receivers still require an upgrade.

Use `replaycase verify incident.nlb --json` for offline verification. Internal
consistency, evidence completeness, and source authenticity remain separate.
Release checksums and evidence bundles are unsigned; matching hashes do not
authenticate the publisher, originating system, or operator.

## Scope

This is a compatible rebrand, not a new protocol or field certification.
Physical Web Serial and manual assistive-technology checks remain separate from
automated browser-engine coverage. The real-source, second-person incident
handoff milestone is still pending. See the [user guide](../../USER_GUIDE.md)
and [changelog](../../CHANGELOG.md) for operation and release details.
