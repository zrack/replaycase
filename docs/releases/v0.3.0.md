# NarrowsLink v0.3.0

NarrowsLink v0.3.0 packages UDP capture-path attribution and the version 4 evidence receiver so recording and receiving engineers can use the same downloadable release.

## Operator changes

- Linux captures can report a measured, capture-scoped UDP socket-drop delta when procfs identifies one process-owned socket. Unsupported platforms and ambiguous counters remain explicitly unavailable, not zero.
- Provenance separates exact payload bytes, deterministic UDP overhead, minimum IP estimates, and unavailable link or radio bytes. Positive measured socket drops remain inspectable capture-path evidence.
- Replay and receiver inspectors expose the counter source and byte-accounting assumptions. The receiver reconciles those claims with the archived records, journal, and receipt.
- Narrow timeline layouts keep the packet-family heading above its labels. Removing an active saved replay preserves its in-memory note even when browser workspace cleanup fails.
- Development dependencies include fixes for the PostCSS and Browserslist advisories documented in the changelog.

## Compatibility and upgrade

v0.3.0 writes version 4 `.nlb` archives and reads versions 3 and 4. v0.2.0 reads version 3 only: upgrade the receiving installation before sending a newly exported bundle. There is no downgrade export. Do not edit an archive to satisfy an older verifier.

Existing version 1 and 2 `.nlsession` documents remain readable and are not rewritten. Earlier local-library records remain supported through verified reopen. Keep the same `http://127.0.0.1:47890` origin and browser profile when upgrading to retain access to the library, markers, notes, and ranges.

## Release assets

- `narrowslink-0.3.0.tgz`
- `narrowslink-0.3.0.release.json`
- `narrowslink-0.3.0.cdx.json`
- `SHA256SUMS`

Verify all three assets against the checksum file before installation:

```bash
shasum -a 256 -c SHA256SUMS
```

On GNU/Linux, use `sha256sum -c SHA256SUMS`. Stop an existing `narrowslink serve` process, then install without lifecycle scripts:

```bash
npm install --global ./narrowslink-0.3.0.tgz --ignore-scripts
narrowslink version --json
narrowslink serve
```

The reported version must be `0.3.0`; compare its full commit with `narrowslink-0.3.0.release.json`. Node.js 20.19 or newer and a local browser are required; no repository checkout or runtime npm dependencies are needed.

## Verification boundary

The annotated-tag release workflow requires the complete source regression, two byte-identical builds, unpacked-package capture-to-verification and maximum-record tests across Chromium, Firefox, and WebKit, and verified asset checksums before publishing.

Loopback UDP and injected Web Serial prove the software pipeline, not physical radio performance, native serial-device behavior, actual multicast infrastructure, or a real-source second-person handoff. Independent field proof and manual assistive-technology certification remain pending. The release, packs, sessions, bundles, and findings remain unsigned: verification establishes internal consistency, not publisher or source authenticity.
