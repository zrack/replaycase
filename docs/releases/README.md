# ReplayCase releases

The latest stable operator package is [ReplayCase v0.4.0](v0.4.0.md).
Use the [user guide](../../USER_GUIDE.md#upgrade-from-narrowslink) when upgrading
an existing NarrowsLink installation.

The next release candidate for v0.5.0 is
[ReplayCase v0.5.0-rc.2](v0.5.0-rc.2.md). Its notes cover tagged-asset verification,
isolated evaluation, multi-bundle cases, managed-runtime shutdown, compatibility,
and the remaining manual verification boundaries. Use only assets attached to
the matching GitHub prerelease after publication and downloaded-asset
verification. Local preview builds do not establish publication, and the
candidate does not replace v0.4.0 as the latest stable release.

**v0.5.0-rc.1: tagged but unpublished (status as of 2026-11-25).** Its
[release verification run](https://github.com/zrack/replaycase/actions/runs/45563107811)
failed before the official build and publication. No official
operator release assets were published for that tag. Its tagged source and
release-note source remain unchanged; source-tag archives are not operator
packages.

Release notes are immutable descriptions of their published tags. Versions
[v0.3.0](v0.3.0.md), [v0.2.0](v0.2.0.md), and [v0.1.0](v0.1.0.md) were published
as NarrowsLink and retain their original package names and commands. They are not
installation instructions for current ReplayCase releases. The
[changelog](../../CHANGELOG.md) owns the full project chronology.
