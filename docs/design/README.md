## Older design artifacts

Other images in this folder are retained historical design or implementation
references. Names containing `final`, `current`, or `production` do not make
them the current accepted baseline. Use the table above and the design QA record
when selecting screenshots for current documentation.

Do not rename or move historical images merely to sort the folder: existing
release notes, reviews, and links may refer to their original paths.
